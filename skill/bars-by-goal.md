# Bar catalog heuristics

Use these when proposing 2–3 bars. Always name a specific live URL or artifact — never a category.

## Site / landing / UI

| Goal flavor        | Candidate bars                                                       |
| ------------------ | -------------------------------------------------------------------- |
| Athletic / running | Nike running campaign; On Running homepage; Gymshark product landing |
| SaaS pricing       | Stripe pricing; Linear pricing; Vercel pricing                       |
| Developer docs     | Tailwind docs; Stripe docs; Expo docs                                |
| Minimal brand      | Apple product page; Notion homepage; Arc browser site                |
| Fintech trust      | Mercury bank; Ramp; Brex                                             |

## Writing

| Goal flavor                        | Candidate bars                                                    |
| ---------------------------------- | ----------------------------------------------------------------- |
| Technical explainer (non-engineer) | A named Julia Evans post; a specific Stripe engineering explainer |
| Opinion / essay                    | A named Paul Graham essay; a specific Lenny’s Newsletter post     |
| News explainer                     | A specific Verge / Bloomberg feature of similar length            |

## Code / CLI

| Goal flavor        | Candidate bars                                              |
| ------------------ | ----------------------------------------------------------- |
| JSON / log tooling | `jq` behavior + man page examples; a named popular CLI’s UX |
| Formatter          | Prettier CLI flags + output; `black --help` style clarity   |
| Benchmarkable      | Named repo’s README benchmark table + its implementation    |

## Games / visual

| Goal flavor    | Candidate bars                                                             |
| -------------- | -------------------------------------------------------------------------- |
| FPS feel       | Real COD / Battlefield footage or official screenshots the critic can open |
| Roguelike      | Hades UI/combat footage; Dead Cells screenshots                            |
| Survivor arena | Brotato store page / gameplay stills                                       |

If footage cannot be fetched, **reject the bar** and ask for a fetchable reference (URL of screenshots, local image set, or a different bar).
